# Supplementary Table S9. Synthetic hs1 reference-contiguity ladder

Synthetic reference assemblies were generated by splitting the same T2T-CHM13 v2.0 (hs1) source FASTA. No bases were added, removed, or masked. Each reference retains 3,117,292,070 total and non-N bases. The corresponding `.map.tsv` file records the original hs1 chromosome and source interval for every synthetic fragment, enabling exact reverse coordinate translation for calls contained within a fragment.

| Synthetic reference | Target contig N50 (bp) | Realised contig N50 (bp) | Number of fragments | Total length (bp) | Non-N bases | Coordinate map |
|---|---:|---:|---:|---:|---:|---|
| hs1_N50000000 | 50,000,000 | 50,000,000 | 75 | 3,117,292,070 | 3,117,292,070 | hs1_N50000000.map.tsv |
| hs1_N10000000 | 10,000,000 | 10,000,000 | 328 | 3,117,292,070 | 3,117,292,070 | hs1_N10000000.map.tsv |
| hs1_N2000000 | 2,000,000 | 2,000,000 | 1,574 | 3,117,292,070 | 3,117,292,070 | hs1_N2000000.map.tsv |
| hs1_N500000 | 500,000 | 500,000 | 6,250 | 3,117,292,070 | 3,117,292,070 | hs1_N500000.map.tsv |

The ladder is an experimental resource. Fresh alignment, structural-variant calling, coordinate translation, and benchmarking against these synthetic references remain to be completed; this table does not report an observed effect of fragmentation on SV recovery.
